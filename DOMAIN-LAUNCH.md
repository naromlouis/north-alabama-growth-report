# NAGR domain launch

Neither custom domain has been purchased or verified. The live Netlify hostname remains the canonical URL until ownership, DNS and HTTPS are confirmed. Do not enable redirects to an unowned or unavailable hostname.

## After purchase

1. Verify control of northalabamagrowthreport.com; add it to the existing Netlify project and follow the DNS records supplied by Netlify for this project. Do not guess DNS targets.
2. Wait for DNS and HTTPS to work, then designate northalabamagrowthreport.com as the primary domain.
3. Change the homepage canonical and og:url to https://northalabamagrowthreport.com/. Also change og:image to https://northalabamagrowthreport.com/assets/nagr-logo.png. Use that origin for future sitemap and structured-data URLs as those are added.
4. If nagr.com is purchased and verified, attach it and www.nagr.com as aliases to this same project, provision HTTPS, and enable permanent host redirects to the primary domain. Preserve paths and query strings. Do the same for www.northalabamagrowthreport.com and the Netlify hostname after the primary domain is working.
5. Check HTTP and HTTPS variants, a path such as /thanks.html, and a query string such as /?source=test. Confirm one destination, no loops, valid certificates, working logo assets and newsletter form.
