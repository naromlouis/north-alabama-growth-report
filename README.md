# North Alabama Growth Report

Official editorial website for North Alabama Growth Report, powered by RockLink.

## Netlify

Existing Netlify site: `north-alabama-growth-report` (Romeo Creates team).

Connect this GitHub repository under Netlify **Project configuration → Build & deploy → Continuous deployment**. Publish directory: `.`; build command: none.

## Editorial workflow

Content is reviewed before committing to `main`. The initial site is a launch preview with links to source reporting; do not represent it as a complete archive.

Netlify Forms collects newsletter interest but does not send newsletters automatically. Configure a compliant mailing service before sending any email.

`.netlify/` is ignored so local Netlify state is not committed.
