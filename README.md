# North Alabama Growth Report

Independent editorial website for North Alabama Growth Report (NAGR).

## Netlify

Existing Netlify site: `north-alabama-growth-report` (Romeo Creates team).

Connect this GitHub repository under Netlify **Project configuration → Build & deploy → Continuous deployment**. Publish directory: `.`; build command: none.

## Editorial workflow

Content is reviewed before committing to `main`. The initial site is a launch preview with links to source reporting; do not represent it as a complete archive.

Netlify Forms collects newsletter interest but does not send newsletters automatically. Configure a compliant mailing service before sending any email.

`.netlify/` is ignored so local Netlify state is not committed.


## NAGR identity and domain readiness

The selected green serif logo with an upward arrow in the A includes the full publication name. Canva logo source: https://www.canva.com/M/MAHaXKo35hA. The local PNG is served from `/assets/nagr-logo.png`; do not hotlink temporary Canva thumbnails.

See [DOMAIN-LAUNCH.md](DOMAIN-LAUNCH.md) before changing domains. Neither planned domain is owned or configured. Keep the current canonical and social URLs until the new primary domain is verified and serving HTTPS, then update all absolute metadata URLs together. Branding changes do not approve new editorial content.
